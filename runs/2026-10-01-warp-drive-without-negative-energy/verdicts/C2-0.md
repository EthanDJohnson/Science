# Verdict on C2 (refuter 0, angle: physics)
claim: The Bobrick–Martire / Fuchs 2024 warp shell is a valid positive-energy coasting vehicle: all four energy conditions hold for all observers below a compactness-set shift cap.
status: final
verdict: weakened
basis: calculation
narrowed: For the published-size shell (C = 0.333, wall Δ/R₂ = 0.5, smoothing span ≳ 1 m), the rebuilt T = G/8π meets all four energy conditions for all observers at every point sampled, at interior shifts β ≲ 0.024; the cap is set by the wall geometry and smoothing (β_crit ≈ 0.10–0.14·C·Δ/R₂) and not by compactness alone, and the construction has no member that meets all four conditions above C ≈ 0.45 at the default smoothing, or above C ≈ 0.8 at any smoothing tried, so it has no Buchdahl-limit cap.

## Strongest attack

The heading makes two claims. First, below some cap all four energy conditions hold. Second, the cap is "compactness-set". The rest of C2's argument depends on the second: it gives a β/C ratio and extrapolates it to Buchdahl caps of "≲ 0.04–0.06 / ≲ 0.08 / ≲ 0.15". My calculations, run with the run's own rebuild and finite-difference Einstein machinery, break that second claim in two ways.

1. **At fixed compactness the cap changes by 10×.** I held C = 2GM/(c²R₂) at 0.3334 (M = 4.49e27 kg, R₂ = 20 m) and thinned the wall. The bisected first NEC failure (all null directions; perpendicular axis and 45° line) fell as follows:
   - β_crit = 0.02383 at Δ = 10 m;
   - 0.00945 at Δ = 5 m;
   - 0.00414 at Δ = 2.5 m;
   - 0.00242 at Δ = 1.5 m.

   So β_crit/C runs from 0.0715 down to 0.0073 at the same C. The cap tracks C·Δ/R₂, with a nonlinear coefficient k = 0.143 → 0.097. The run's own variants already pointed the same way: a buffer R_b = 1–2 m gives a cap of 0.016–0.010, and linear theory gives β_max → 0 for thin walls. A cap that drops tenfold at fixed C is not set by compactness.

2. **Above moderate compactness, every β fails.** Here the claim breaks outright for the shell family C2 names. With zero shift, the static shell is Hawking–Ellis type I, so the DEC check is exact: max(|p_r|, |p_t|)/ε ≤ 1. At the default smoothing (span_P = 0.1Δ), the DEC already fails with no shift at all above these compactnesses:
   - C_DEC = 0.453 for Δ/R₂ = 0.5 (the published geometry);
   - 0.386 for Δ/R₂ = 0.25;
   - 0.366 for Δ/R₂ = 0.125;
   - 0.362 for Δ/R₂ = 0.075.

   The failure sits at the smoothed remnant of the hoop-stress sheet at R₁, where P(R₁) ≠ 0. Widening the smoothing helps only up to a point. At C = 0.8 the ratio is still 1.73 with a 4 m span. At C = 0.85 the bulk of the uniform-density TOV wall already has P(R₁)/ε = 1.27, so no smoothing can save it.

   So for this construction the "cap" is zero from C ≈ 0.45 (default smoothing), or at the latest from C ≈ 0.8 (any span tried), up to the Buchdahl bound. C2's Buchdahl-limit caps (≲ 0.04–0.08) extrapolate NEC thresholds into a region where the DEC fails at β = 0. They do not exist.

   The same problem appears inside C2's own variant table: "the ratio to compactness falls from 0.082 to 0.066 as C runs 0.083–0.5". At C = 0.5 with the published wall and default smoothing, the zero-shift DEC ratio is 1.22. The "all four conditions" cap there is zero, not 0.066 × 0.5 ≈ 0.033. Only the NEC threshold exists at that point.

What does not fall: at the published configuration the energy-condition pass at β = 0.02 is reproduced. The run's sampled tests (0 of 850 points fail), M-CONSTRAINTS-06, M-DECOMPOSER-08 and my own β_crit = 0.02383 on the same lines all agree. The paper says the same thing. So a positive-energy shifted shell exists, at least as T = G/8π sampled pointwise, and the core survives in a narrower form.

Assumption check:
- β_crit is bisected on two radial lines only, so each value is an upper bound on the true onset. The thickness trend can only get steeper.
- The static DEC test is exact, because the shell is type I with diagonal T.
- The failures at high C are properties of the paper's construction: a uniform-density initial guess, TOV pressure with P(R₂) = 0, and moving-average smoothing. Other density profiles are not ruled out. An Israel thin static shell meets the DEC up to 2M/R = 24/25 (M-IDEALIZER-03), but a thin wall drives β_crit → 0 (finding 1).
- No calculation here, or in the run, exhibits a profile that has both high compactness and a nonzero all-condition cap.

## In principle vs. in practice

- **In principle:** survives in narrowed form. A shell with a nonzero interior shift and a T = G/8π that meets all four conditions at every sampled point exists at C ≈ 0.33 with a thick, smoothly edged wall, at β ≲ 0.024. The cap is a functional of the wall profile (thickness, smoothing, buffer), roughly 0.1–0.14·C·Δ/R₂. It is not a function of C alone, and this construction offers none at all above C ≈ 0.45–0.8.
- **In practice:** unchanged from C2's own accounting:
  - 22 orders of magnitude above demonstrated mass;
  - stresses 27.6 orders above 1 TPa;
  - no matter model;
  - stability unknown.

  The thickness scaling makes it worse. A cap of β ≈ 0.02 needs a thick wall (Δ ≈ R₂/2) at C ≈ 0.33. Thinner, lighter-looking walls lose the shift almost proportionally.

## Corrections to details

- "a compactness-set shift cap" should read: a cap set by compactness, wall thickness and edge profile, β_crit ≈ (0.10–0.14)·C·Δ/R₂ for this construction.
- The Buchdahl-limit caps "≲ 0.04–0.06 / ≲ 0.08 / ≲ 0.15" should be withdrawn for this shell family. Above C ≈ 0.45 at the default smoothing, and above C ≈ 0.8 for spans up to 4 m, the DEC fails at β = 0.
- The variant row "ratio falls from 0.082 to 0.066 as C runs 0.083–0.5" is an NEC-only ratio. At C = 0.5 the all-four-conditions cap is zero at the default smoothing.
- "Scale-invariant to R₁ = 100 m" is right for scaling the whole shell at fixed C and Δ/R₂, as M-CONSTRAINTS-06b confirms. It does not make the cap compactness-set.

## What survives and remaining doubt

What survives:
- The existence claim stands at the published configuration: β = 0.02 passes all four conditions at every sampled point, and β_crit ≈ 0.0239.
- "Coasting vehicle" is trivially true. Any speed v < c is a boost of the static solution.

Remaining doubts, which are not mine to settle by calculation:
- The energy-condition pass is a property of T = G/8π for a rebuild whose smoothing span is the toolkit's choice, not the paper's.
- Points are sampled, not certified.
- No matter model with its own equations of motion reproduces the shifted wall. The stationary momentum currents need flowing or anisotropic matter.
- Linear stability is uncomputed.

A non-uniform density profile might raise both the DEC compactness ceiling and the thickness coefficient k. Until someone shows one, the narrowed claim above is the defensible core.
