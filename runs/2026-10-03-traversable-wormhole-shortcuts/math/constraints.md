- M-CONSTRAINTS-02: for C² functions Φ, r on ℝ with r > 0, (e^{−Φ}(2Φ′r′ − 2r″)/r)·(1/(8π)) = −(1/4π)e^{−Φ}(r′/r)² + d/dl[−(1/4π)e^{−Φ}r′/r]; hence if e^{−Φ}r′/r → 0 at ±∞ and r′ ≢ 0, the integral over ℝ is strictly negative.
- M-CONSTRAINTS-06: for V(a) = 1 − 2M/a − (2πσ(a)a)² with σ′ = −(2/a)(σ+P), P′ = β²σ′ and σ(a0), P(a0) as given, V″(a0) = 0 iff β² = −(1−3x+3x²)/(2(1−2x)(1−3x)), x = M/a0 ∈ (0, 1/2) \ {1/3}.

- M-CONSTRAINTS-13: for T_thru, T_ext, Δ ≥ 0, t + T_thru − Δ + T_ext ≤ t iff Δ ≥ T_thru + T_ext; and T_ext/T_thru < 1 iff T_thru > T_ext.
