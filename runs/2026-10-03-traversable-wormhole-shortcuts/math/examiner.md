Notes on scope:
- **M-01:** the model assumes static mouths and a constant Δ, as the lens states. It says nothing about whether any physical process can set Δ.
- **M-04:** τ = π r_e/c is the proper time between turning points inside the AdS₂ region. T_thru = πℓ/c leaves out the exterior legs between r = 2r_e and the matching region. Those legs add a few light-seconds against 9.4×10³ yr.
- **M-05:** the closed form holds up to corrections of O(ρ_c/γ) and O(1/ρ_c²). At ρ_c = 10⁹, the relative shift is 1.8×10⁻⁵.
- **Not checked, because they are quoted and not derived:** MMP ratio > 2 (Q-12), FGM 2019 t_min = d + logs (Q-13), the FGM 2018 t* formula (Q-14), and the GJW formula itself (Q-15). MSY and Graham–Olum are qualitative statements.

## Formalizable
- M-EXAMINER-01: for real T_w > 0, X > 0 and Δ, a two-node weighted digraph has A→B edges {T_w + Δ, X} and B→A edges {T_w − Δ, X}. It has a negative-weight cycle iff |Δ| > T_w + X. The A→B shortest path is the throat edge iff Δ < X − T_w. The set {Δ : Δ < X − T_w and |Δ| ≤ T_w + X} is an interval of length 2X.
- M-EXAMINER-04: ∫_{−∞}^{∞} dρ/(1 + ρ²) = π. For every e > 1 with A = √(e² − 1): ∫_{−A}^{A} dρ/√(A² − ρ²) = π, and ∫_{−A}^{A} e dρ/((1 + ρ²)√(A² − ρ²)) = π.
- M-EXAMINER-05: for γ > 0 and ρ_c > 0, asinh ρ_c + (1 − ρ_c/γ) + ln(γ/ρ_c) − [ln(2γ) + 1] → 0 as ρ_c → ∞ with ρ_c/γ → 0.
- M-EXAMINER-06: (d/(Gv))/(d/v) = 1/G, for d, G, v > 0.
