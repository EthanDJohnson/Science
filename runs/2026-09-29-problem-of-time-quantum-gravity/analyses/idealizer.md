# Analysis: idealizer (Plato)

## Method applied
Three simplest models that still contain the problem of time, each solved exactly and numerically: (M1) a finite-dimensional Page–Wootters universe (clock ⊗ system, one constraint), used to test ideal, finite, gravitationally coupled and generically coupled clocks, Kuchař's two-time objection, and thermal time; (M2) a one-heavy-variable "minisuperspace" constraint solved exactly and by Born–Oppenheimer/WKB, used to test emergent Schrödinger time, the inner product, turning points and clock choice; (M3) a two-level or rest-mass clock whose proper time is set by a classical background or by a source mass in superposition. Scaling laws are extracted, idealizations are relaxed one at a time, and the largest departure from reality (one global constraint instead of local constraints) is named.

## Findings

F1. **M1, ideal clock: the frozen formalism (facet 1) is dissolved exactly in the idealized model.** A d = 8 equally spaced clock (H_C eigenvalues -3.5..3.5 rad/s, hbar = 1) and a qubit (H_S = sigma_x/2, rad/s) in the null space of J = H_C⊗1 + 1⊗H_S: the conditional states track exp(-i H_S t) psi0 with minimum fidelity 1.000000 (to 1e-16) and constant norm (|norm²-1| < 5e-16) over one period. The global state is stationary and the dynamics is entirely relational, as [D-05], [D-06] and [U-01] state. [calc: runs/2026-09-29-problem-of-time-quantum-gravity/calc/lens-idealizer_pw_model.py]

F2. **M1, Kuchař's two-time objection reproduced and answered in the same model.** Naive two-time probability P(1 at t2 | 0 at t1) built from clock projectors on the physical state [K-03]: exactly 0 at lattice separations 0.785, 1.571, 2.356 (dimensionless time), and also 0 at off-lattice separations 0.1 and 0.3 where textbook QM gives 2.50e-3 and 2.23e-2. With a memory register (Giovannetti–Lloyd–Maccone construction), the same universe gives 0.146447, 0.500000, 0.853553, equal to |<1|U(t2-t1)|0>|² to 1e-6. So the objection is a statement about the naive conditioning rule, not about the constraint: a record-bearing subsystem restores two-time predictions without an external time. This supports the reply side of [D-19] within the model; it does not supply the independent assessment [D-19] notes is missing. [calc: same file]

F3. **M1, interacting clock (Smith–Ahmadi Newtonian mass-energy coupling H_CS = -lam H_C⊗H_S): gravitational time dilation appears as a relational redshift.** The conditional dynamics is exactly unitary with H_eff = H_S (1 - lam H_S)^-1: effective qubit gap 1/(1-lam) rad/s for bare gap 1 rad/s (lam = 1e-3 ... 0.1, fidelity with exp(-iH_eff t) = 1 to 1e-12). Against the bare H_S, the fidelity drops as 1 - F ≈ sin²(lam·Δ·t/2) (lam = 1e-3, t = 20: 1-F = 1.0e-4). Scaling law: fractional frequency shift = lam·E_S + O(lam²), with lam = hbar G/(c⁴ x) in seconds (SI). This is the idealized version of "GR time dilation inside a timeless quantum constraint". [calc: same file]

F4. **M1, generic (non-gravitational) clock–system coupling makes relational evolution non-unitary, linearly in the coupling.** Random Hermitian H_CS = g·V (||V|| = 1 rad/s) on a d = 6 clock + qubit: the exact null space is empty for any g > 0 (the resonance is detuned by about 0.14 g–0.6 g in the two smallest |eig J|), so the constraint must be retuned. After retuning, the effective conditional generator has non-Hermiticity 4.5e-4, 4.5e-3, 4.7e-2 for g = 1e-3, 1e-2, 1e-1 rad/s: non-unitarity ≈ 0.45 g/ω_clock (dimensionless), i.e. linear in coupling. The gravitational coupling of F3 is special (it factorizes as a product of Hamiltonians, so the result is only a redshift). This is the model counterpart of [D-20] and [K-09]: exact unitarity (HSL) holds for the non-interacting idealization, while realistic coupling gives GPP-type non-unitarity whose size is set by the coupling. [calc: same file]

F5. **M1, the ideal clock is a limit; resolution scales as T/d.** Half-overlap time of the time states t_half = 0.970, 0.477, 0.237, 0.1185, 0.0592 for d = 4, 8, 16, 32, 64 (period T = 2π): t_half·d ≈ 3.8 (dimensionless), and the covariant POVM resolves the identity (defect < 3e-15). The ideal clock (spectrum = R, a constraint linear in the clock momentum, as in unimodular time [D-11] or dust time [D-10]) is the d → ∞ limit. This matches [D-17] and the Pauli/Unruh–Wald escape via POVMs [K-02]. [calc: same file]

F6. **M1, thermal time agrees with relational time only for Gibbs weights.** The system's reduced state from the PW physical state is diagonal in energy; its modular Hamiltonian K = -ln rho_S generates a flow proportional to H_S only if K_n - K_0 = beta(E_n - E_0) for one beta. 3-level system E = 0, 1, 3 rad/s: Gibbs weights give ratio 0.7, 0.7 (single beta; modular flow = PW time rescaled by beta), non-Gibbs weights (0.5, 0.2, 0.3) give 0.916 and 0.170 (no single beta; modular flow is a different "time"). For a qubit every diagonal state is Gibbs, so the discrepancy needs ≥ 3 levels. So thermal time [D-12] is a state-dependent time that coincides with the clock time only in an equilibrium-like state; this sharpens the circularity worry [D-24] into a concrete condition. [calc: same file]

F7. **M2, semiclassical time emerges with a correction quadratic in H_S, scaling as 1/M.** One heavy variable x (mass M, the stand-in for m_P²) plus a 3-level system (E = 0, 1, 2.5; heavy energy per unit mass e0 = 50; model units, hbar = 1) under one constraint [-(1/2M)∂²_x - M e0 + H_S]Ψ = 0, solved exactly (plane waves k_n = sqrt(2M(M e0 - E_n))). With the WKB time t = x/v, v = sqrt(2 e0), the conditional state obeys i∂_t χ = H_S χ at O(M⁰) and i∂_t χ = [H_S + H_S²/(2Mv²)]χ at O(M⁻¹). At t = 10: 1-F(order 0) = 1.89e-4, 1.88e-6, 1.88e-8, 1.88e-10 for M = 10, 100, 1e3, 1e4, matching the prediction t²Var(H_S²)/(2Mv²)² to 3 digits; the O(1/M) corrected equation brings 1-F to 1.3e-9 (M = 10) and below machine precision for M ≥ 1e3. Scaling law: phase error per unit time = E_S²/(2 M v²) = E_S × (E_S / 4K_heavy), with K_heavy = Mv²/2. This is the structure reported by Kiefer–Singh ("the only surviving correction contains the square of the matter Hamiltonian", [D-09]) and the (E/m_P)² suppression [Q-17], [Q-18]. [calc: runs/2026-09-29-problem-of-time-quantum-gravity/calc/lens-idealizer_bo_minisuperspace.py]

F8. **M2, the inner-product facet (3) returns at the same order as the correction.** When the heavy energy varies along x (e from 25.3 to 74.7 over the run, M = 100), the Klein–Gordon current k_n|ψ_n|² of each component is conserved exactly (ODE check at M = 3: 21.354708 → 21.354708 and 21.000561 → 21.000561), but the Schrödinger-norm populations drift (level 2: 0.3334211 → 0.3333631, level 0: 0.3332566 → 0.3333073). Size: O(E_S/(M e)) × (fractional change of e), here ~2.5e-4 per unit fractional change. So "which inner product" is not a free choice beyond leading order: the Schrödinger norm is only approximately conserved, the KG norm is conserved but (in the full theory) not positive definite. This is the model counterpart of Kiefer–Singh's "gravitationally induced violation of unitarity" [D-09] and of facet 3 [D-02]. [calc: same file]

F9. **M2, global time (facet 4) fails only in a window around turning points, whose size shrinks as M^(-2/3).** For a heavy variable with a turning point (linear potential, slope g = 1), the exact solution is an Airy function of width ℓ = (2M²g)^(-1/3): ℓ·M^(2/3) = 0.7937 for M = 10 ... 1e4, and the semiclassical-time window where the clock x stalls is Δt ~ sqrt(2ℓ/g) ∝ M^(-1/3) (0.585 → 0.0585 over M = 10 → 1e4). Outside, the WKB wave matches Airy to 4.5e-2, 1.1e-2, 3.3e-3 at 1, 3, 10 widths. At the turning point the state is a standing wave, a superposition of the "expanding" and "recollapsing" branches, and the conditional system state is a superposition of exp(-iH_S t) and exp(+iH_S t) branches; separating them needs decoherence or a better clock. This reproduces the model-specific clock pathology of [D-03] (a "quantum recollapse" in scalar-field time) in its simplest form. [calc: same file]

F10. **M2, multiple choice (facet 2) enters at the same O(1/M) order.** With two heavy variables whose kinetic energies Mv² differ (Mx v_x² = 1e4, My v_y² = 3e3 model units), deparametrizing with x or with y gives the same Schrödinger equation at O(M⁰) but correction coefficients 5.0e-5 vs 1.67e-4, i.e. a relative phase 7.3e-3 rad after t = 10 for E_S = 2.5. Clock dependence is therefore an effect of the same size as the first quantum-gravity correction, consistent with the "equations and corrections are different" result of [D-21]. (This part is an analytic illustration from the single-clock formula, not a separate exact solve.) [calc: same file]

F11. **M3(a), proper time in superposition on a classical background is already within reach of existing clocks, and it does not touch the problem of time.** Sr clock (ω = 2π × 429.2 THz) in a superposition of heights Δh on Earth (g = 9.807 m/s²): Δφ/t = ωgΔh/c² = 2.94e-4, 2.94e-3, 0.294, 2.94 rad/s for Δh = 1 mm, 1 cm, 1 m, 10 m; the visibility first vanishes at t = πc²/(ωgΔh) = 1.07e4, 1.07e3, 10.7, 1.07 s. The classical-background frequency shift itself is already measured over 1 mm [D-14], [Q-06]. This tests QM + GR on a fixed metric (hidden premise 1): QFT on curved spacetime already handles it, so it cannot discriminate positions on the problem of time ([F-09] says the same of the proposed experiments). [calc: runs/2026-09-29-problem-of-time-quantum-gravity/calc/lens-idealizer_superposed_time.py]

F12. **M3(b,c), the genuine conflict (a superposed geometry) is only observable through the rest-mass "Compton clock", and that experiment is the gravity-mediated-entanglement test.** A fixed optical clock near a source mass in a superposition of distances d1/d2 needs m* = c²/(ωG(1/d1 - 1/d2)t) for a 1 rad proper-time phase in 1 s: 1.8e8 kg (200/450 µm), 1.0e9 kg (1/2 mm), 1.0e10 kg (1/2 cm). Replacing the optical clock with the rest-mass clock ω_C = mc²/ħ = 8.5e36 rad/s of a 1e-14 kg partner (3.2e21 times faster) gives Δφ = Gm²t(1/d1 - 1/d2)/ħ = 0.176 rad (t = 1 s), 0.440 rad (t = 2.5 s), identical to the QGEM gravitational phase formula. (The dossier's 0.23/0.57 rad [Q-10] uses a different geometric convention, G m²/d with d = 450 µm; same order.) So "time dilation in a superposition of geometries" and "gravity-mediated entanglement" [Q-09], [D-23] are one observable in the idealized model. The relational positions (PW, semiclassical, thermal, unimodular) all predict this phase at leading order; classical-gravity and collapse positions predict its absence or suppression ([F-05], [F-06]). [calc: same file]

F13. **M3(d,e), everything that separates the "conservative" positions from each other is suppressed by Planck-scale factors.** Smith–Ahmadi relational-clock coupling lam = ħG/(c⁴x) = 8.7e-76 s at x = 1 mm; its fractional effect on an optical clock lam·ω = 2.4e-60 (dimensionless). Semiclassical WDW correction (E/m_P)² with m_P = 2.65e19 GeV [Q-17]: 4.5e-57 (1.77 eV photon), 2.8e-31 (14 TeV, matching [Q-18]), 1.4e-7 (1e16 GeV, inflation-era scale). Only the early universe gives a correction above ~1e-10; this is why [F-03] looks to the CMB and why the dossier found no discriminating laboratory number (dossier section 6, "No discriminating observation among the 'conservative' positions"). F15. **Literature check of F3/F4 (clocks coupled through mass-energy).** [new: Castro-Ruiz, Giacomini & Brukner 2017, PNAS 114, E2303 (arXiv:1507.01955), abstract via fetch_text, "the clocks necessarily get entangled through time dilation effect, which eventually leads to a loss of coherence of a single clock. However, the general relativistic notion of time is recovered in the classical limit of clocks."] In M1 this is the H_C⊗H_S coupling of F3: conditioning on a sharp reading of the clock gives exactly unitary evolution with a redshifted generator, while tracing over a clock in an energy superposition gives dephasing of the system at a rate of order lam·ω_S·ΔE_C (from the same generator, not separately simulated). Both hold for the same state; they are different operations. This is how the model reconciles exact relational unitarity (HSL) with realistic-clock decoherence (GPP, Castro-Ruiz et al.) in [D-20].

### 4. Where reality departs most from the models, and whether that helps or hurts

The largest departure is the step from **one global constraint to a Hamiltonian constraint at every point of space**, with the hypersurface-deformation algebra. M1 and M2 each have a single constraint, so facet 5 (functional evolution) and the ultraviolet and anomaly issues are absent by construction. This **hurts** every "resolution" candidate: the clean model results (exact relational unitarity, a single O(1/M) correction) are exactly what the local theory is not known to deliver. [K-01] shows non-unitary evolution between generic Cauchy surfaces already for a free field on flat R × T^n, and [K-04] shows semiclassical time is consistent only if the full theory is anomaly-free. The second-largest departure is **branch decoherence**, put in by hand in M2. It **helps** semiclassical time in practice (decoherence selects one WKB branch and suppresses the F9 interference), but it makes the position depend on an interpretation of QM (hidden premise 8). The third is the **positive-definite inner product** in M1, which flatters the relational picture; F8 shows the indefinite KG structure returns at O(E/M).

## What would change my mind

- A field-theoretic (local-constraint) construction in which a relational clock gives clock-independent, unitary evolution between arbitrary hypersurfaces: that would weaken D and strengthen A and E.
- An independent published analysis showing the HSL/GLM two-time construction fails for Klein–Gordon constraints across sectors, or when the memory is itself gravitating: that would weaken A (F2 rests on the idealized memory).
- A QGEM-type experiment showing no entanglement with decoherence controlled below the gravitational phase: that would move F from strained to surviving and eliminate the leading-order prediction shared by A, B, C, E.
- A demonstration that the (E/m_P)² semiclassical correction is clock-independent at O(1/M) in a realistic minisuperspace: that would weaken F10 and the multiple-choice part of D.
- A physical argument that the states relevant for gravity are KMS/Gibbs-like with respect to physical clocks: that would lift G from strained.
