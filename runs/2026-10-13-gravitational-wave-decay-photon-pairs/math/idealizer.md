## Refuted
None. Every checked derivation agrees with an independent one. Two corrections, neither of which changes a finding's direction:
- M-IDEALIZER-07: the cycle-averaged standing-wave f(x) does not tend to 1.2. It oscillates between 0.91 and 1.82 with x-average 1.364 (= 3 Int P^4 dOmega/L^2). The lens's 1.21 is the mean of five samples and is 11 per cent low, so the standing-wave proxy's agreement with eq. 8's total (R(>1) = 1.008 in F6) should read about 1.1 (see M-08). That is still O(1) agreement, so F6 and [IDEALIZER-A] stand.
- M-IDEALIZER-07/08: the outgoing f is exactly A x^-2 asymptotically (A = 0.2274 for m = 2, 0.3410 for m = 0), not x^-2.02 or x^-2.10. So the far-zone law is R(>x) = 0.0632 x^-3 (m = 2), and F8's 0.069 x^-3 is 9 per cent high. F14's alternative extrapolation x^-3.024 is a fit artefact. The exact exponent supports F8's choice of a pure x^-3.
## Unverified
- M-IDEALIZER-14: the physical-pattern factors (0.562, 0.3125, 0.225, the exact zero for pure circular) and F13's coherent-versus-kinetic ratio (0.982, 0.931) are toolkit outputs. This check did not re-derive them. F7, F13 and [IDEALIZER-B]'s "x0.3-0.6" rest on them. F8's 1.65e-6 pairs and the 1.25e3 stimulated pairs use 0.562; that arithmetic is verified in M-09, but the factor itself is not.
- M-IDEALIZER-15: F12 (binning neither lowers nor raises the total) is supported by the exact profile-free law (M-04) but not computed for a chirp. It fails for simultaneous (non-chirping) bands, where binning gives 1/n of the total.
- Scope: M-07/08 check the scalar l = 2 toy as the lens defines it. Whether the kinetic proxy Gamma = (2 pi/5) G^2 <T><T> with a cycle-averaged T describes the coherent yield of a single curved outgoing front is a physics assumption, not mathematics. The lens flags it too.
## Formalizable
- M-IDEALIZER-02: 2 pi Int_{-1}^{1} (Int_0^{2 pi} (1 - (1 - c^2) cos^2 phi) dphi)^2 dc / [2 x 2 pi Int_{-1}^{1} (Int_0^{2 pi} (1 + (1 - c^2) cos^2 phi) dphi)^2 dc] = 7/54.
- M-IDEALIZER-04: for g in L^1 and L^2 of R, with a(t) = Int g(u) e^{-iut} du: Int abs(a)^4 dt = 2 pi Int abs(g*g)^2 du, and for g = exp(-u^2/2): (3/2) Int (g*g)^2/(Int g^2)^2 = (3/2) sqrt(2 pi).
- M-IDEALIZER-06: for null vectors k_i = w_i(1, n_i) and T = sum n_i k_i k_i^T/w_i, tr(eta T eta T) = sum_ij n_i n_j w_i w_j (1 - n_i.n_j)^2; it vanishes iff all n_i coincide (for positive n_i).
- M-IDEALIZER-12: for w1, w2 > 0 with w1 + w2 <= 2E and 2 w1 w2 (1 - cos th) >= 4, with 1 <= E: 1 + cos th <= 2 - 2/E^2.
- M-IDEALIZER-13: 2 w1 w2 (1 - c) <= (w1 + w2)^2 for all real w1, w2 >= 0 and c in [-1, 1].
