# Check: Blas & Oller, "Gravitational waves decay in vacuum" (arXiv:2607.24930)

This folder is an independent check of the paper's claim that gravitational waves decay into photon pairs through graviton fusion. It was made while developing the `qft_*` calculators in `.claude/skills/conundrum/scripts/`; it is not a /conundrum run. The findings are in `report.md`: a bottom line, the paper's claims quoted verbatim, a verdict table, evidence by topic, and caveats. Four analyses fed it: amplitudes and helicity phases; the space-time structure of the coherent state; the δ(0) → T step; and the stochastic background, CMB stimulation and ultralight dark matter. Adversarial referees challenged each analysis, and a critic re-ran the scripts.

Every number in the report is printed by a script in `calc/`, and its output log is in `notes/`. Run scripts from this folder with `python3 calc/<script>.py [--part ...]`; the report's section 7 lists them with their arguments. The scripts need numpy, mpmath, sympy and scipy. Fourteen of them import the repository's `qft_second_order.py` (none imports `qft_production.py`), and every module output a verdict rests on is cross-checked by an independent route, such as `bo_common.py`'s spinor-helicity double copy. A few scripts take several minutes; `taskD2_cmb_stimulation.py` should be run part by part.
